# חדר המורים אורט שחקים

אתר סטטי להצגת תורנויות היום לפי מתחם, הודעות חשובות, תאריך עברי ולועזי ומזג אוויר.

## פרסום באמצעות GitHub Pages

1. היכנסו ל-GitHub וצרו repository חדש, למשל `ort-shakim-staff-screen`.
2. העלו לריפוזיטורי את `index.html` ואת `.nojekyll` מתוך התיקייה הזו.
3. היכנסו ל- **Settings → Pages**.
4. תחת **Build and deployment**, בחרו `Deploy from a branch`.
5. בחרו בענף `main` ובתיקייה `/ (root)`, ואז לחצו **Save**.
6. המתינו לסיום הפרסום. כתובת האתר תופיע באותו מסך תחת GitHub Pages.

## שימוש

- פתחו את כתובת האתר בדפדפן שמחובר לטלוויזיה.
- לחצו על **מסך ניהול** כדי לערוך שיבוצים והודעות.
- לחצו **שמירת שינויים** כדי לשמור בדפדפן המקומי.

## מגבלה חשובה

זו גרסה סטטית: עריכות נשמרות ב-`localStorage` של הדפדפן והמכשיר שבו בוצעו. הן אינן נשלחות ל-GitHub ואינן מסתנכרנות אוטומטית בין מחשב הניהול לטלוויזיה אם הם משתמשים במכשירים או בדפדפנים שונים. כדי לקבל ניהול מרחוק ועדכון בזמן אמת בין מכשירים, צריך לחבר את האתר לשירות backend/מסד נתונים, למשל Firebase או Supabase, ולהגדיר הרשאות מתאימות.

מזג האוויר נטען משירות Open-Meteo, ולוגו בית הספר נטען מהקישור החיצוני שסופק. לכן נדרש חיבור לאינטרנט.
